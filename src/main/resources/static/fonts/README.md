# 폰트 자산

현재 웹 UI는 **Pretendard Variable v1.3.9**를 자체 호스팅합니다. 본문·제목·버튼·입력·내비게이션에 동일하게 적용하고 첫 화면에서 미리 로드합니다. 외부 폰트 CDN 요청은 없습니다. 원본 Toss Product Sans와는 다른 서체입니다.

- 원본: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
- 웹 파일: `PretendardVariable.woff2`
- SHA-256: `9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4`
- 같은 버전의 공식 라이선스: [Pretendard-OFL.txt](Pretendard-OFL.txt)

기존 Wanted Sans와 PDF용 폰트 자산은 보존합니다.

- 원본: https://github.com/wanteddev/wanted-sans
- 고정 원본 커밋: `02c9b822349c188ada95f9e2d90c2ed18f853235`
- 웹 파일: `WantedSansVariable.woff2`
- PDF용 파일: `src/main/resources/pdf-fonts/WantedSans-Regular.ttf`, `WantedSans-Bold.ttf`
- Wanted Sans 라이선스·저작권 고지: [WantedSans-OFL.txt](WantedSans-OFL.txt)
- 기존 Pretendard 라이선스: [OFL.txt](OFL.txt)

원본 폰트를 변형하거나 재명명하지 않았습니다. Wanted Sans는 SIL Open Font License 1.1로 배포됩니다. 독립적인 폰트 판매 등 라이선스가 금지하는 용도로 사용하지 않습니다.
